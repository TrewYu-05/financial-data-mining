# 《金融与经济数据挖掘》作业3分析报告：二因子模型与PEG策略回测

## 一、 数据获取与预处理总结
1. **收益率与超额收益计算**：使用了 `baostock` 获取6只股票及沪深300指数 2018-01-01 至 2025-12-31 的日频前复权收盘价数据，并计算日度百分比收益率。对于无风险利率，按照文档要求固定使用 $R_f = 1.5\%$（年化），转化为日度无风险收益率参与超额收益计算。
2. **异常值处理**：通过 `scipy.stats.mstats.winsorize` 将各股票及市场的收益率及PETTM数据在上下1%的极值进行缩尾处理，避免极端市场情况（如停牌复牌暴涨暴跌）干扰回归模型。
3. **PETTM归一化**：在2018-2022年样本内分别寻找每只股票的PETTM极大值与极小值，使用最小-最大归一化将PETTM映射至 [0,1] 区间，消除不同股票估值绝对水平的量纲差异。对回测期（2023-2025年），使用样本内计算出的极值进行转换，以避免引入“未来函数”。

## 二、 CAPM 与 二因子模型拟合分析

模型拟合主要使用了 2018-2022 年样本内的数据。相关回归指标详见生成的 `model_results.csv`。

### 1. 因子暴露分析（$\beta_2$ 含义及大小）
在二因子模型中，$\beta_2$ 是归一化PETTM的回归系数：
- **正暴露**代表个股超额收益与估值呈**正相关**，即估值越高时，超额收益越高，通常具有动量或高成长特征的市场表现。
- **负暴露**代表个股超额收益与估值呈**负相关**，即估值越高时，超额收益越低（出现“均值回归”），具有典型的价值投资特征。
- 由于不同行业的增长预期和市场关注度不同，估值对短期收益的影响方向和强度表现出显著的差异。

### 2. CAPM 与 二因子模型 $\alpha$ 系数对比
将CAPM扩展为包含PETTM的二因子模型后，个股的 $\alpha$ 发生了改变：
- 传统单因子 CAPM 模型下的 $\alpha$ 包含了大量未能被大盘系统性风险解释的“异象”。
- 加入PETTM（估值因子）后，模型对资产定价的解释力增强，原本被包含在 $\alpha$ 中的由于估值波动带来的收益被 $\beta_2$ 分离出来。如果某股票的异常收益主要来源于估值修复或泡沫破裂，引入二因子模型后，其截距项 $\alpha$ 的绝对值通常会减小（趋向于0），说明原有的定价异象部分被估值因子所解释。

### 3. 基于行业的拟合结果差异及逻辑
分析的6只股票主要覆盖四个行业：
- **白酒（贵州茅台、五粮液、泸州老窖）**：消费龙头，高毛利高ROE，常年享受估值溢价。其PETTM因子可能具有特定的暴露特征（如随大盘消费情绪波动），这导致其估值变动对超额收益的解释力较强。
- **能源（中国石油）**：传统周期股，盈利受宏观经济和原油价格影响大，利润增速波动大且常年处于低估值状态。其对于估值的变动更为敏感，具有较强的防御性和均值回归属性。
- **金融（招商银行）**：银行股资产规模大、盈利稳定，PETTM极低且波动小。对这类股票，估值因子的解释力度可能较为有限，收益更多来源于宏观流动性和信用周期的驱动。
- **家电（美的集团）**：可选消费代表，兼具价值与一定成长性，估值相对平稳。其对于估值的反应往往介于高弹性的科技股和低弹性的银行股之间。

## 三、 PEG 策略回测分析

在2023-2025年的样本外期间进行回测。使用前五年的平均利润增长率作为固定指标，结合动态的归一化PETTM生成每日PEG信号。

### 1. 回测策略与规则
- **计算PEG**：$PEG = 归一化PETTM / 五年利润平均增长率$。若个别股票（如中国石油）增长率极低或波动较大，则可能引发极端PEG值。
- **交易规则**：
  - $PEG < 0.8$：全仓买入。若有多个标的，选择**二因子模型下$\alpha$最高**的股票。
  - $PEG > 1.5$：全仓卖出（空仓观望）。
  - $0.8 \le PEG \le 1.5$：保持当前持仓不变。
- 考虑到实际投资情况，每次调仓收取 0.03% 的手续费，并假定 0.1% 的交易滑点。

### 2. 回测效果不佳的原因探讨（结合回测结果）
从回测指标（参见 `backtest_metrics.csv` 及收益曲线）来看，PEG策略在该特定时间段可能未能显著跑赢基准（沪深300），探讨原因如下：
1. **宏观经济环境与市场风格切换**：2023-2024 年期间，A股整体处于震荡下行与风格快速切换期。此时高成长、高估值股票遭到抛售，“高息低估”红利资产受捧。单纯依赖过去的五年（2018-2022，其中包含白酒等核心资产估值大幅扩张期）来计算平均利润增速，极可能存在**历史增速高估**的情况。
2. **PEG指标失效的局限性**：由于利润增速采用静态的5年算术平均，未能反映个股近期的盈利恶化。导致计算出的 PEG 被人为低估，发出了“错误”的买入信号，陷入所谓的“价值陷阱”。
3. **策略频繁触发止损/调仓**：在熊市震荡期间，估值可能反复在 0.8 和 1.5 的阈值间跳动。频繁满仓切换股票或清仓，加上双边千分之一点三的交易摩擦成本，显著侵蚀了净值。

### 3. 策略改进方向
1. **动态更新利润增速预测**：采用滚动过去3年/或加入分析师一致预期（Forward EPS）的增长率代替固定的过去5年历史均值，以更贴合企业真实的当期成长能力。
2. **引入大盘择时过滤**：当沪深300等宽基指数处于明确的均线空头排列时，直接屏蔽买入信号，增加策略的防御性。
3. **增加个股质量过滤**：除了PEG外，可以结合ROE（净资产收益率）或自由现金流等质量因子，过滤掉虽然估值便宜但盈利能力持续下滑的“烂票”。
4. **平滑调仓逻辑**：将“全仓买卖”修改为“分批建仓/动态权重”，减少冲击成本。
