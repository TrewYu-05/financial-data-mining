# CAPM 模型实现与回测分析报告

本报告基于 2020-01-01 至 2022-12-31 的日度交易数据，利用 CAPM 模型对 6 只股票（贵州茅台、中国石油、五粮液、泸州老窖、招商银行、美的集团）进行了拟合，并选取理论 Alpha 最高的股票在 2023-01-01 至 2024-12-31 期间进行了长期持有回测。

## 1. 单股分析：每只股票是否存在显著 Alpha？贝塔系数反映何种波动特征？

根据模型拟合结果（见下表）：

| 股票 | α(Alpha) | β(Beta) | Alpha P-Value | Beta P-Value |
| :--- | :--- | :--- | :--- | :--- |
| 贵州茅台 | 0.0008 | 1.1115 | 0.1433 | 0.0000 |
| 中国石油 | -0.0001| 0.3528 | 0.8993 | 0.0000 |
| 五粮液 | 0.0008 | 1.4862 | 0.2229 | 0.0000 |
| 泸州老窖 | 0.0018 | 1.5704 | 0.0338 | 0.0000 |
| 招商银行 | 0.0001 | 1.0543 | 0.8766 | 0.0000 |
| 美的集团 | 0.0001 | 1.1269 | 0.8662 | 0.0000 |

**Alpha 显著性分析：**
在显著性水平 $\alpha = 0.05$ 的标准下，仅**泸州老窖**的 Alpha 存在统计学意义上的显著（P-Value = 0.0338 < 0.05）。其余 5 只股票的 Alpha 的 P-Value 均大于 0.05，说明这些股票在统计上并未表现出显著的异于市场回报的超额收益。

**Beta 波动特征分析：**
所有股票的 Beta 系数均极其显著（P-Value = 0.0）。
- **β > 1（高波动特征）：** 泸州老窖（1.57）、五粮液（1.49）、美的集团（1.13）、贵州茅台（1.11）和招商银行（1.05）。这说明它们的价格波动幅度大于沪深300指数。其中，白酒板块（尤其是泸州老窖和五粮液）具有较高的进攻性和较高的系统性风险暴露，在牛市能获得更高收益，但在熊市也会面临更大跌幅。
- **β < 1（低波动/防御特征）：** 中国石油（0.35）。其走势相对独立于整体股票市场，受大盘波动的直接影响较小，呈现出防御性资产的特征（受宏观周期及商品价格影响更大）。

## 2. 对比分析：6 只股票的 Alpha、Beta 差异及行业/基本面原因

**Alpha 差异原因：**
泸州老窖在拟合期间表现出最高且唯一显著的 Alpha。这可能归因于：在 2020-2022 年期间，白酒行业尤其是高端和次高端白酒，凭借其强大的品牌护城河、提价能力和业绩确定性，在复杂的宏观环境下依然实现了超预期的盈利增长。相比之下，传统的金融（招商银行）、制造（美的集团）和能源（中国石油）更多受宏观经济周期和疫情等系统性因素压制，难以获得脱离大盘的超额收益。

**Beta 差异原因：**
- **消费白马股（白酒、家电）：** 泸州老窖、五粮液、贵州茅台的 Beta 普遍较高。由于外资（北向资金）和公募基金在拟合期间大量抱团这些核心资产，导致资金同向交易频繁，其波动与大盘（以沪深300为代表的蓝筹指数）高度共振甚至放大，因此 Beta 大于 1。
- **金融地产链（招行）：** 招商银行作为大金融板块的核心，其市值占比较大，Beta 接近 1（1.05），基本上代表了市场的系统性表现。
- **能源周期（中国石油）：** 中国石油处于上游资源端，其业绩更多受到国际原油价格周期的影响，而非单纯的国内流动性或内需变化。因此其走势与国内宽基指数的相关性较低，Beta 值（0.35）显著偏低。

## 3. 核心思考题

**本次回测选择了理论 Alpha 最高的股票（泸州老窖）长期持有，最终是否获得了预期的超额收益？**

**没有获得预期的超额收益。**
回测结果显示：
- **泸州老窖累计收益率：** -42.53%，最大回撤高达 -60.46%，卡玛比率为 -0.40。
- **沪深300基准收益率：** 1.51%，最大回撤 -24.80%，卡玛比率为 0.03。

在 2023-2024 年的回测期内，理论上 Alpha 最高的泸州老窖大幅跑输了沪深300指数，不仅没有实现超额收益，反而造成了严重的绝对亏损。

**为什么理论上的 Alpha 收益，在真实市场中很难拿到？**

结合市场逻辑，原因主要包括以下几个维度：
1. **Alpha 的非平稳性与均值回归（市场波动）：** 历史数据的拟合（2020-2022）反映的是过去的特质性表现，但 Alpha 往往不具备长期持续性。一旦前期抱团资金解散、行业增速预期下调（如2023年后白酒消费降级预期），原本的正 Alpha 会迅速均值回归甚至转负。
2. **风险暴露（高 Beta 放大亏损）：** 泸州老窖的 Beta 高达 1.57。在 2023-2024 年国内宏观复苏不及预期、大盘整体震荡下行的环境下，高 Beta 特征使其在市场下跌时跌幅远大于大盘。系统性风险（Beta）的兑现完全吞噬并掩盖了任何可能的特质性收益（Alpha）。
3. **宏观与基本面逻辑反转：** 历史拟合期内高 Alpha 的股票，往往是因为其当时的基本面处于扩张周期的顶峰。当进入回测期（2023-2024）后，宏观经济进入新的周期，过去的盈利逻辑（如消费升级）不再适用。
4. **持股周期的僵化：** 策略规定“长期持有不做任何买卖操作”。在真实的 A 股市场，由于较高的波动率，择时（控制回撤）和动态再平衡非常重要。无脑长期持有单只高弹性股票，极易承受无法挽回的深度回撤（如本例中高达60%的回撤）。
5. **投资者情绪与拥挤度交易：** 历史上的高 Alpha 标的通常伴随着极高的市场关注度和机构持仓拥挤度。当边际增量资金枯竭，存量博弈下情绪反转，极易发生“杀估值”现象。

**结论：** CAPM 模型计算出的历史 Alpha 仅仅是后视镜中的“残差”，不能直接等同于未来的超额预期。在真实市场中，试图单纯依赖历史高 Alpha 股票并长期持有来获取超额收益，面临着极高的风格反转和系统性波动风险。
